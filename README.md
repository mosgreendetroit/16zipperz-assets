# 16zipperz-assets

Public marketing pin images for the [16Zipperz vintage reseller store](https://16zipperz.gumroad.com).

These 1000×1500 (2:3) graphics are hosted so social tools can use a stable, direct image URL.

Direct URL pattern:

`https://raw.githubusercontent.com/mosgreendetroit/16zipperz-assets/main/pins/<filename>`
